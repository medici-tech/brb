## 1. Game Overview

### Concept
A narrative-driven idle game that satirizes modern American politics. Players are interviewed about their rise to power, then their answers determine which archetype they become: **Politician, Televangelist, Cult Leader, Oligarch, or Demagogue**. From there, they build their empire through timed actions, resource management, and commentary from internal "advisor" voices—mechanics borrowed from Crusader Kings 3 (dynasty/relationships) and Disco Elysium (ideological identity and internal monologue).

### Core Loop
1. **Passive resource generation** — Money, Influence, Approval tick upward automatically
2. **Player actions** — Click to start time-locked tasks (Buy Ads, Rally Supporters, etc.)
3. **Resource acceleration** — Spend resources to speed up actions
4. **Advisor reactions** — Internal voices comment on actions and decisions
5. **Win/loss checks** — Game state progresses toward victory or collapse

### Target Audience
- Idle game enthusiasts (Cookie Clicker, Adventure Capitalist)
- Narrative game fans (Disco Elysium, Papers Please)
- Political satire fans (Veep, The Thick of It)
- Strategic game players (CK3, Crusader Kings)

## 2. Core Mechanics

### Mechanic 1: The Prologue (Character Creation)

**Function:**
Player answers 5 interview questions. Each answer is recorded and influences starting stats and advisor set.

**Example Questions:**
- "When did you first realize people would believe anything you told them?"
- "What's your relationship with the law?"
- "What do you believe in?"
- "What scares you most?"
- "How far would you go?"

**How It Works:**
- Interviewer asks one question per screen
- Player selects from 3-4 answers (multiple choice)
- Each answer is tagged with archetype: `politician`, `televangelist`, `cult_leader`, `oligarch`, `demagogue`
- After 5 questions, tally votes
- Archetype with most votes wins
- Set starting stats based on archetype
- Hire default advisor set
- Transition to main game

**Why This Matters:**
- Sets tone (dark, satirical)
- Disco Elysium "conversation as character creation"
- Makes player complicit in their role
- Each answer is logged for potential "mirror" voice commentary later

**MVP Version:** Simplified to 5 questions, single archetype (Politician)

---

### Mechanic 2: Three-Resource Economy

**Resources:**

| Resource | What It Represents | Generated By | Used For |
|---|---|---|---|
| **Money** | Dark money, donations, PACs, bribes | Idle passive rate + actions | Speeding up actions, advisor actions |
| **Influence** | Political capital, favors owed, leverage | Relationships, actions | Speeding up political actions, keeping people quiet |
| **Approval** | Public polling, social media followers, votes | Actions, media presence | Speeding up public-facing actions, unlocking opportunities |

**Generation Rates:**
- **Base passive:** Each resource ticks up every game loop tick (500ms)
  - Money: +1 every tick (≈60/second, ≈3,600 per minute)
  - Influence: +0.5 every tick
  - Approval: +0.3 every tick

- **Multipliers:**
  - Advisor bonuses: "Bundler speeds up money by 20%" = +1.2x passive generation
  - Archetype bonuses: Oligarch gets +50% money generation
  - Event debuffs: Scandal hits → Approval multiplier drops to 0.5x for 2 minutes

**Interaction:**
- High Approval makes all public actions faster (people want to hear you)
- Money can buy almost anything but at a premium
- Influence matters for hidden actions (backroom deals) but not public ones
- The satire: Money > Influence > Approval in effectiveness

**MVP Version:** Base passive only, no multipliers yet. Simple linear generation.

### Mechanic 3: Actions System

**Function:**
Actions are player-initiated tasks with a cost, duration, and reward. Each action advances the player toward their win condition.

**Action Structure:**

```
Action: "Buy Ads"
├─ Cost: Money (5,000), Influence (0), Approval (0)
├─ Base Duration: 3,600 seconds (1 hour)
├─ Speedup Options:
│  ├─ Spend $2,500 more Money → Duration = 1,800 sec (50% faster)
│  ├─ Spend 50 Influence → Duration = 2,700 sec (25% faster)
│  └─ Spend 100 Approval → Duration = 2,700 sec (25% faster)
├─ Reward on Completion:
│  ├─ Approval +500
│  ├─ Follower Count +50
│  ├─ Money -5,000 (cost applied upfront)
├─ Advisor Bonuses:
│  ├─ Bundler: -20% duration (money specialist)
│  ├─ Pollster: +250 Approval on completion
│  └─ Mirror: "That's it. You're buying them now. Nice."
├─ Unlock Requirement: Available to all archetypes
└─ Cooldown: None (can queue immediately after)
```

**Action Types (MVP):**

| Action | Archetype | Cost | Duration | Reward | Flavor |
|---|---|---|---|---|---|
| Buy Ads | All | 5k Money | 1 hr | +500 App, +50 followers | "Flood the market" |
| Rally Supporters | All | 2k Money, 50 Influence | 2 hrs | +1000 App, +100 followers | "Get them in a room" |
| Take Donation | All | None | 30 min | +3k Money | "Call a donor" |

**How Actions Work:**

1. **Player clicks action button** → Deduct cost from resources
2. **Start timer** → Display progress bar
3. **Advisor bonuses applied** → Calculate new duration with speedup factors
4. **Idle loop ticks timer down** → Every 500ms check elapsed time
5. **On completion** → Apply rewards, trigger advisor comments, check win/loss

**Speedup Mechanic:**
- Player CAN click the action again mid-progress to spend additional resources
- Each spend gives diminishing returns:
  - First spend: -20% duration
  - Second spend: -10% duration
  - Third spend: -5% duration
- Encourages strategy: "Do I rush this or let it idle?"

**MVP Version:** 3 core actions, no cooldown, no advanced speedup logic yet.

### Mechanic 4: Advisor System

**Function:**
Advisors are hired helpers that provide passive bonuses and commentary on player actions.

**Advisor Structure:**

```
Advisor: "The Bundler"
├─ Archetype: Politician
├─ Personality: "Cheerfully corrupt. Never asks questions."
├─ Specialty: Money actions (speeds them up by 20%)
├─ Base Cost: 1,000 Money (one-time hire)
├─ Comments:
│  ├─ On action start: "That's the spirit. Money talks."
│  ├─ On action complete: "Beautiful. Clean work."
│  ├─ On low Money: "We're hemorrhaging capital. Time to spend."
│  └─ On loss trigger: "Well, this is awkward."
├─ Upgrade Path: None (MVP)
└─ Special Rules: None (MVP)
```

**Available Advisors (MVP):**

| Advisor | Bonus | Specialty |
|---|---|---|
| **The Bundler** | +20% Money generation | Money specialist |
| **The Pollster** | +10% Approval generation | Approval specialist |
| **The Mirror** | None (debugging voice) | Confronts player choices |

**How Advisors Work:**

1. **Hire an advisor** → Pay one-time cost, add to roster
2. **Passive bonus** → Advisor's specialty multiplier applies to resource generation
3. **Action bonus** → If action matches specialty, reduce duration by X%
4. **Commentary** → Trigger advisor comment on game events

**The Mirror (Special Advisor):**
- Not hired; always present
- Can be **silenced** by player (action: "Silence the Mirror" costs 500 Influence)
- If silenced, doesn't generate comments
- If you keep them alive, they unlock "True Win" conditions later
- Represents player's conscience

**MVP Version:** 3 advisors, 1 comment per event, no upgrade trees.

### Mechanic 5: The Idle Loop

**Function:**
The heartbeat of the game. Every 500ms, the game updates state and checks conditions.

**Tick Function (Pseudocode):**

```javascript
const tick = () => {
  // 1. Generate passive resources
  const passiveGen = calculatePassiveGeneration(
    gameState.advisors,
    gameState.archetype,
    gameState.approval // high approval = faster generation
  )
  gameState.money += passiveGen.money
  gameState.influence += passiveGen.influence
  gameState.approval += passiveGen.approval

  // 2. Progress active action
  if (gameState.activeAction) {
    const elapsed = now() - gameState.activeAction.startTime
    if (elapsed >= gameState.activeAction.duration) {
      completeAction(gameState.activeAction)
    } else {
      updateProgressBar(elapsed / duration)
    }
  }

  // 3. Check win condition
  if (gameState.followers >= gameState.winCondition.target) {
    triggerWin()
  }

  // 4. Check loss conditions
  if (gameState.approval <= 0 && gameState.money <= 0) {
    triggerLoss('irrelevance')
  }

  // 5. Random events (later)
  // if (Math.random() < eventChance) { triggerRandomEvent() }

  // 6. Save state (optional, every 10 ticks)
  if (gameState.tickCount % 10 === 0) {
    saveToLocalStorage(gameState)
  }
}

setInterval(tick, 500) // Run every 500ms
```

**Why 500ms?**
- Fast enough to feel responsive (4x per second)
- Slow enough to not murder performance
- Standard for idle games (Cookie Clicker uses 100ms, but that's more aggressive)

**MVP Version:** Basic tick, 3 resources, 1 action, no events.

### Mechanic 6: Win/Loss Conditions

**Win Conditions (Archetype-Specific):**

| Archetype | Primary Win | Requirement | Narrative |
|---|---|---|---|
| **Politician** (MVP) | Reach Presidency | 10,000 followers + 50,000 Approval | Win election |
| Televangelist | Media Empire | 50M followers + 1B network value | Build the network |
| Cult Leader | The Compound | 1,000 loyal followers + self-sufficient | Ascend |
| Oligarch | Own 3 institutions | Control stake in major orgs | Become the system |
| Demagogue | Declare Emergency | Approval > 50k + trigger event | Take over |

**Win Sequence:**
1. Player hits threshold → Trigger "Epilogue" phase
2. Show advisor reactions (3-4 scenes)
3. News montage of your victory (satirical)
4. Offer post-win options: New Game+, Switch Archetype, The Convergence

**Loss Conditions:**

| Loss Type | Trigger | Recovery | Narrative |
|---|---|---|---|
| **Irrelevance** | Money = 0 AND Approval = 0 | None (game over) | You fade from relevance |
| **Whistleblower** | Mirror defects if silenced too long | None (game over) | Your secrets go public |
| **Cascade Failure** | Critical resources all < 100 simultaneously | Maybe (hard) | Everything collapses at once |

**Loss Sequence:**
1. Loss condition triggered
2. Advisor final comments (Mirror especially harsh)
3. Epilogue text describing irrelevance
4. Offer: New Game+, Different Archetype

**MVP Version:** Single win condition (10k followers), single loss condition (Irrelevance), no recovery.

## 3. Game Functions & How They Interconnect

```
┌─────────────────────────────────────────────────────────────────┐
│                     GAME STATE (GameContext)                    │
│  - Resources (Money, Influence, Approval)                       │
│  - Active Action (if any)                                       │
│  - Advisor roster                                               │
│  - Archetype                                                    │
│  - Win/Loss flags                                               │
└─────────────────────────────────────────────────────────────────┘
                              ↓
        ┌─────────────────────┼─────────────────────┐
        ↓                     ↓                     ↓
   ┌─────────────┐    ┌────────────────┐    ┌────────────────┐
   │ IDLE LOOP   │    │ ACTION SYSTEM  │    │ ADVISOR SYSTEM │
   │  tick()     │    │  executeAction │    │  getBonus()    │
   │             │    │  completeAction│    │  triggerComment│
   │ Generates   │    │                │    │                │
   │ resources   │    │ Costs resources│    │ Modifies timers│
   │ every 500ms │    │ Starts timers  │    │ Provides flavor│
   └─────────────┘    │ Applies rewards│    └────────────────┘
        ↓             └────────────────┘            ↑
        │                    ↑                       │
        │ Updates            │ Calls on complete    │
        │ resources          │                      │
        ↓                    ↓                      │
   ┌────────────────────────────────────────────────────────┐
   │           WIN/LOSS CHECK                               │
   │  - Followers reached? → WIN                            │
   │  - All resources 0? → LOSS                             │
   │  - Mirror defected? → LOSS                             │
   └────────────────────────────────────────────────────────┘
        ↓
   ┌────────────────────────────────────────────────────────┐
   │              UI UPDATE                                 │
   │  - Progress bars (action timers)                       │
   │  - Resource counters (Money, Influence, Approval)     │
   │  - Advisor comments (dialogue box)                     │
   │  - Status messages (follower count, archetype)        │
   └────────────────────────────────────────────────────────┘
```

**Data Flow Example: Player starts "Buy Ads"**

```
1. UI: Player clicks "Buy Ads" button
   ↓
2. ACTION SYSTEM:
   - Read action config: Cost 5k Money, 1 hr duration
   - Deduct from gameState.money
   - Create gameState.activeAction = { id: 'buy_ads', startTime: now(), duration: 3600000 }
   ↓
3. ADVISOR SYSTEM:
   - Check if "Bundler" is hired
   - If yes: duration *= 0.8 (20% faster)
   - Store updated duration
   ↓
4. UI:
   - Hide "Buy Ads" button
   - Show progress bar (0%)
   - Show countdown timer
   ↓
5. IDLE LOOP (ticks every 500ms):
   - Check: elapsed time >= duration?
   - Update progress bar: elapsed / duration
   - No completion yet, repeat
   ↓
6. [After 50 minutes with Bundler bonus]
   - IDLE LOOP: elapsed >= duration → true
   - ACTION SYSTEM: completeAction('buy_ads')
   ↓
7. ACTION SYSTEM applies onComplete:
   - gameState.approval += 500
   - gameState.followers += 50
   - Clear gameState.activeAction
   ↓
8. ADVISOR SYSTEM triggers comments:
   - Bundler: "Beautiful. Clean work."
   - Pollster: "Approval bumped. We're trending."
   ↓
9. WIN/LOSS CHECK:
   - Is followers >= 10000? → No
   - Is approval <= 0 AND money <= 0? → No
   ↓
10. UI:
    - Hide progress bar
    - Show new Approval: 1500 → 2000
    - Show advisor comments
    - Show "Buy Ads" button again (can queue another action)
```

## 9. Known Risks & Mitigation

| Risk | Impact | Mitigation |
|---|---|---|
