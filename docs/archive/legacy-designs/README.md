# Legacy BRB Designs

These documents preserve earlier versions of BRB. Their original bodies remain intact, but their mechanics, technology choices, schedules, and status labels are superseded.

## Early political idle-game concepts

These versions used passive resource ticks, timed actions, interview-selected political archetypes, React/Vite, and a planned Capacitor conversion. The current game instead uses discrete monthly commitments, five active resources, three operating doctrines, and a pure TypeScript engine with a Next.js interface.

## Doomsday and advisor-driven concepts

These versions shifted toward advisors and global pressure, but still relied on idle timers, dominance tracks, or a Doomsday Clock. The current game replaced those systems with permanent BRB deposits, adaptive Corporation pressure, Situation Cards, and open-ended monthly campaigns.
