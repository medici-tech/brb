# Big Red Button — Complete Game Design Document (GDD)

**Title:** Big Red Button
**Genre:** Narrative Idle Game with Political Satire
**Platform:** Web (React) → iOS (Capacitor) Week 2
**Target Audience:** Idle game fans, narrative lovers, political satire enthusiasts
**Status:** Ready for Implementation
**Version:** 1.0 - Final

---

## 1. Game Overview

### Concept
A narrative-driven idle game where players are interviewed about their rise to power. Their answers determine which archetype they become: **Politician, Televangelist, Cult Leader, Oligarch, or Demagogue**. From there, they build their empire through timed actions, resource management, and commentary from internal advisor "voices"—mechanics inspired by Crusader Kings 3 (dynasty/relationships/traits) and Disco Elysium (ideological identity + internal monologue).

The game's central metaphor: **The Big Red Button**—a nuclear option available at endgame that forces a final choice: press it for instant victory (if you can afford it) or grind the slow path to power. Different archetypes have wildly different outcomes.

### Core Loop
1. **Prologue:** Answer 5 interview questions → determines archetype and starting stats
2. **Idle tick (500ms):** Resources generate passively, timers progress
3. **Player actions:** Click to spend resources and time on ambitious tasks
4. **Advisor reactions:** Internal voices comment on everything you do
5. **Resource acceleration:** Spend resources to speed up actions
6. **Win/loss checks:** Progress toward victory or collapse
7. **Big Red Button:** Late-game nuclear option that forces a final choice

### Tone & Satire
- **Surface level:** Dark, cynical, funny. Politics is absurd.
- **Deep level:** Bleak realization that all paths—Politician, Televangelist, Cult Leader, Oligarch, Demagogue—use identical mechanics. No "good" path exists.
- **Final message:** Every archetype leads to the same consolidation of power. The Mirror (your conscience) watches as you become the system.

## 2. The Prologue: Character Creation

### How It Works
Player answers **5 sequential interview questions**. An interviewer (unseen, ominous tone) asks about the player's past. Each answer is tagged with archetype scores.

### Example Questions & Answers

**Question 1: "When did you first realize people would believe anything you told them?"**
- "As a preacher's kid" → +2 Televangelist
- "On the campaign trail" → +2 Politician
- "After my first Instagram post went viral" → +2 Cult Leader / +1 Demagogue

**Question 2: "What's your relationship with the law?"**
- "It's a tool" → +2 Politician / +2 Oligarch
- "It exists to be exploited" → +2 Demagogue / +2 Oligarch
- "What law?" → +2 Cult Leader

**Question 3: "What do you believe in?"**
- "People. The righteous masses." → +2 Televangelist / +2 Demagogue
- "Myself" → +2 Oligarch / +2 Demagogue
- "The cause" → +2 Cult Leader

**Question 4: "What scares you most?"**
- "Being ordinary" → +2 Demagogue / +2 Politician
- "Losing control" → +2 Cult Leader / +2 Oligarch
- "Being found out" → +2 Politician / +1 all

**Question 5: "How far would you go?"**
- "As far as it takes" → +2 all archetypes (wildcard)
- "I have limits" → +1 Televangelist (but blocks some paths)
- "Further than I should" → +2 Demagogue / +2 Oligarch

### Archetype Selection
After 5 questions, tally the votes. Highest score wins. If tied, show player both options and let them choose.

### Starting State
- **Archetype chosen** → Determine advisor roster and starting bonuses
- **Starting resources:**
  - Money: 2,000
  - Influence: 100
  - Approval: 500
  - Followers: 0

- **Hired advisors:** 2 default advisors (depends on archetype)
- **Unavailable:** Unlock higher-tier advisors through gameplay

## 3. Three-Resource Economy

### Resources

| Resource | Represents | Generated By | Used For |
|---|---|---|---|
| **Money** | Dark money, donations, PACs, speaking fees | Passive idle + actions | Speeding up nearly all actions, hiring advisors |
| **Influence** | Political capital, favors owed, leverage | Actions, relationships | Speeding political actions, bribing, backroom deals |
| **Approval** | Public polling, social media followers, votes | Actions, media presence | Speeding public actions, unlocking opportunities |

### Generation Rates

**Base Passive (per idle tick, 500ms):**
- Money: +1 per tick (~60/sec, ~3,600/min, ~216k/hour)
- Influence: +0.5 per tick
- Approval: +0.3 per tick

**Multipliers:**
- Advisor bonuses: Bundler (Politician) +20% money generation
- Archetype bonuses: Oligarch +50% money generation
- Event debuffs: Scandal → Approval multiplier drops to 0.5x for 2 minutes (future)
- Approval multiplier: High approval (>5k) increases all generation by 10-30%

**MVP Version:** Base passive only, no multipliers. Simple linear generation.

### Economy Satire
- **Money is king:** Can speed almost everything, but at premium cost
- **Influence matters for politics only:** Useless for public-facing actions
- **Approval is a feeling:** Doesn't actually speed much, but affects long-term sustainability
- **The joke:** Money > Influence > Approval in actual effectiveness

## 4. Actions System

### Action Structure

Every action has:
- **Base Cost** (Money, Influence, Approval)
- **Base Duration** (in seconds)
- **Reward** (on completion)
- **Advisor Bonuses** (speed multipliers)
- **Archetype Restrictions** (who can do it)
- **Comments** (what advisors say)

### MVP Actions (Week 1)

| Action | Cost | Duration | Reward | Advisor Bonus | Flavor |
|---|---|---|---|---|---|
| **Buy Ads** | 5k Money | 1 hr (3600s) | +500 App, +50 followers | Bundler: -20% | "Flood the market with your message" |
| **Rally Supporters** | 2k Money + 50 Influence | 2 hrs (7200s) | +1000 App, +100 followers | Pollster: +250 App | "Get them fired up in person" |
| **Take Donation** | None | 30 min (1800s) | +3k Money | Bundler: -20% | "Call a major donor" |

### How Actions Work

1. **Player clicks action** → Confirm dialog shows cost
2. **Deduct cost immediately** (fail if insufficient resources)
3. **Create active action** with timer (baseTime - advisor bonuses)
4. **Display progress bar** and countdown
5. **Idle loop ticks** (every 500ms)
6. **On completion:**
   - Apply reward
   - Trigger advisor comments
   - Check win/loss conditions
   - Clear active action
   - Player can queue next action immediately

### Speedup Mechanic (Future)

Players can **click action again mid-progress** to spend additional resources and reduce remaining time:
- First spend: -20% remaining time
- Second spend: -10% remaining time
- Third spend: -5% remaining time
- Diminishing returns encourage decision-making

**MVP:** No speedup system. Just let actions complete naturally.

## 6. The Idle Loop (500ms Tick)

### Pseudocode

```javascript
function gameTick() {
  // 1. Passive resource generation
  const passiveGen = calculatePassiveGeneration(
    gameState.advisors,      // advisor multipliers
    gameState.archetype,     // archetype bonuses
    gameState.approval       // high approval bonus
  )
  gameState.money += passiveGen.money
  gameState.influence += passiveGen.influence
  gameState.approval += passiveGen.approval

  // 2. Progress active action
  if (gameState.activeAction) {
    const elapsed = now() - gameState.activeAction.startTime
    const duration = gameState.activeAction.duration

    if (elapsed >= duration) {
      completeAction(gameState.activeAction)
    } else {
      updateProgressBar(elapsed / duration)
    }
  }

  // 3. Check Big Red Button unlock
  if (gameState.followers >= 5000 &&
      gameState.money >= 25000 &&
      gameState.approval >= 2000) {
    gameState.bigRedButtonAvailable = true
  }

  // 4. Check win condition
  if (gameState.followers >= gameState.winThreshold) {
    triggerWin('normal')
  }

  // 5. Check loss conditions
  if (gameState.money <= 0 && gameState.approval <= 0) {
    triggerLoss('irrelevance')
  }

  // 6. Save to localStorage (every 10 ticks)
  if (gameState.tickCount % 10 === 0) {
    saveGameState()
  }

  gameState.tickCount++
}

setInterval(gameTick, 500) // Every 500ms
```

### Why 500ms?
- **Responsive:** 4 updates per second feels smooth
- **Performant:** Doesn't murder the CPU or battery
- **Standard:** Cookie Clicker uses 100ms (aggressive), our game is less aggressive
- **Idle-game appropriate:** Shows progress without demanding attention

## 7. Big Red Button: The Nuclear Option

### Concept
The button is a late-game catastrophic action that forces a final choice: **instant victory (if you can afford it) or slow grind to traditional win.**

It perfectly embodies the game's satire: the nuclear option is tempting, risky, and ultimately just another path to the same consolidation of power.

### Unlock Conditions
Button appears when ALL of these are true:
- Followers ≥ 5,000
- Money ≥ $25,000
- Approval ≥ 2,000
- ≥ 20 minutes elapsed

### Visual & UX
- **Appearance:** Pulsing red button in bottom-right corner when unlocked
- **Icon:** ⚠️ or radioactive symbol
- **Tooltip:** "Warning: Irreversible action"
- **Interaction:** Click → confirmation modal
- **Modal text:** "This button represents your final move. There is no undo. Are you sure?"

### What Happens When Pressed

#### Outcome 1: VICTORY (if resources sufficient)

**Condition:** Money ≥ 25k AND Approval ≥ 2k

**Result:**
- Immediate win
- Bypass normal win threshold
- Trigger epilogue
- Button press felt impactful

**Advisor Reactions:**
- Bundler: "This is it. No going back now."
- Pollster: "The polls can't predict this."
- Mirror: "You actually did it. And for what?"

**Epilogue Text (Politician example):**
> "You pressed it. Martial law declared. Democracy suspended. You're in total control. The country is on fire, but at least YOU'RE holding the extinguisher."

#### Outcome 2: MUTUAL DESTRUCTION (if resources insufficient)

**Condition:** Money < 25k OR Approval < 2k

**Result:**
- Instant catastrophic loss
- Game ends immediately
- Cannot be undone
- Final message from Mirror

**Advisor Reactions (pre-loss):**
- Bundler: "You... you can't afford this."
- Pollster: "The numbers don't support this."
- Mirror: "You're about to find out how fragile this is."

**Loss Message:**
> "You pressed it. So did everyone else. The fallout is mutual, absolute, and irreversible. You thought you were in control. You never were."

## 8. Win & Loss Conditions

### Win Conditions

| Path | Requirement | Result |
|---|---|---|
| **Standard Win** | Followers ≥ 10,000 | "You've won. Epilogue sequence." |
| **Button Press (Victory)** | Button pressed with sufficient resources | "Instant victory through catastrophe." |

### MVP Win Threshold
- **Followers ≥ 10,000**
- Reach this through normal gameplay (Buy Ads, Rally, Donations)
- Takes ~30-40 minutes of moderate engagement

### Loss Conditions

| Condition | Trigger | Recovery | Narrative |
|---|---|---|---|
| **Irrelevance** | Money = 0 AND Approval = 0 | None | Slow fade into obscurity. No one remembers you. |
| **Mutual Destruction** | Press Big Red Button with insufficient resources | None | Everything collapses at once. Your fault. |

### MVP Loss Condition
- **Irrelevance:** Money ≤ 0 AND Approval ≤ 0
- Game doesn't give dramatic "Game Over" screen
- Resources slowly drain to zero
- Final advisor comment (Mirror especially harsh)
- Offer to restart or try different archetype

## 12.5. Visual Progression: Kairosoft Aesthetic

### Concept
The game's visual style **evolves in real-time** as the player rises or falls in power. This mirrors the game's central message: success is beautiful until it becomes grotesque.

Inspired by Kairosoft's charming pixel aesthetic but with a satirical twist — the more powerful you become, the more ostentatious and slightly disturbing the UI becomes.

### Visual Progression Stages

#### Stage 1: Grassroots (Followers: 0-2,000)
**Vibe:** Humble, scrappy, DIY energy

- **Color palette:** Muted grays, dark blues, minimal contrast
- **UI elements:** Simple, minimal borders, flat design
- **Advisor icons:** Small, simple pixel portraits (16x16)
- **Background:** Empty, sparse office/campaign space
- **Animations:** Slow, subtle (minimal movement)
- **Resource counters:** Plain numbers, no flourish
- **Typography:** Small, clean, corporate-looking fonts

**Flavor:** You're starting from nothing. The interface reflects desperation.

#### Stage 2: Rising (Followers: 2,000-5,000)
**Vibe:** Growing, gaining momentum, professional

- **Color palette:** Introduce brand colors (reds, golds, corporate blues)
- **UI elements:** Slightly more ornate borders, subtle shadows
- **Advisor icons:** Larger, more detailed pixel portraits (24x24)
- **Background:** Small office expands, furniture appears, posters on walls
- **Animations:** Medium speed, slight bounces and transitions
- **Resource counters:** Numbers with icons, slight emphasis
- **Typography:** Slightly larger, more prominent

**Flavor:** You're building something. The interface shows ambition.

#### Stage 3: Consolidating (Followers: 5,000-8,000)
**Vibe:** Powerful, established, slightly ostentatious

- **Color palette:** Gold accents, jewel tones, more vibrant colors
- **UI elements:** Ornate borders, significant shadows and depth, 3D-ish appearance
- **Advisor icons:** Detailed pixel portraits (32x32) with halos/auras
- **Background:** Grand office, marble floors, mahogany desk, painting on wall
- **Animations:** Fast, responsive, celebratory (bounces, spins)
- **Resource counters:** Large numbers with currency symbols, glowing effects
- **Typography:** Large, bold, all-caps sections

**Flavor:** You're in control. The interface celebrates your power.

#### Stage 4: Absolute Power (Followers: 8,000-10,000)
**Vibe:** Grotesque, excessive, dictatorial

- **Color palette:** Blood red, gold, black, overly saturated colors
- **UI elements:** Massive ornate borders, extreme shadows, almost baroque
- **Advisor icons:** Exaggerated, grotesque pixel art, bug-eyed, oversized
- **Background:** Absurd palace room, golden furniture, too many decorations, statues of yourself
- **Animations:** Rapid, excessive, slightly janky/broken feeling
- **Resource counters:** Massive numbers with $$$, flashing and glowing
- **Typography:** Huge, all-caps, tacky fonts, excessive decorations

**Flavor:** You've won, but the UI itself looks unhinged. This is a warning.

#### Loss State: Deterioration (if Approval + Money both hit 0)
**Vibe:** Falling apart, decaying, irrelevant

- **Color palette:** Faded, desaturated, grays and browns
- **UI elements:** Cracked borders, missing shadows, pixelated corruption
- **Advisor icons:** Faded, pixelated faces, tears, resignation
- **Background:** Empty, abandoned office, boarded windows, decay
- **Animations:** Slow, laggy, stuttering (intentional performance degradation)
- **Resource counters:** Zeroed out, grayed out, fading text
- **Typography:** Blurry, small, almost unreadable

**Flavor:** You're being forgotten. The interface is rotting.

|---|---|---|---|---|---|

### Kairosoft-Specific Details

**Pixel Art Style:**
- Use CSS pixel fonts (Courier New) for retro feel
- Icons are 8-bit style (hand-drawn or generated)
- Character portraits are cute-grotesque (Kairosoft charm but unsettling)
- Slight scanlines overlay (optional, very subtle)

**Advisor Portraits:**
- Stage 1: Simple, cute Kairosoft-style avatars
- Stage 2: More detailed, slightly smug expressions
- Stage 3: Exaggerated features, golden chains, crowns
- Stage 4: Grotesque, oversized heads, bug eyes, cackling expressions

**Background Changes:**
- Stage 1: Empty gray office, single desk, window shows gray city
- Stage 2: Furniture appears, motivational posters, better lighting
- Stage 3: Mahogany desk, oil paintings, marble floors, statue in corner
- Stage 4: Too much gold, statues everywhere, absurd throne-like chair, grotesque murals

**Interactive Elements:**
- Stage 1: Buttons are flat, minimal
- Stage 2: Buttons have subtle shadows
- Stage 3: Buttons have ornate frames
- Stage 4: Buttons pulse with gold, excessive animations, almost broken

---

### Why This Matters

The visual progression **reinforces the game's satire:**
- Early game: You sympathize with the struggling protagonist
- Mid-game: The ambition feels justified, the aesthetics celebrate it
- Late game: You realize how grotesque it's become, but you're committed
- Loss: The beautiful facade crumbles. You're forgotten.

The player doesn't need to be *told* they're becoming corrupt — the UI **shows** them. That's the Disco Elysium move applied to visuals.

## 14. Technical Stack

| Layer | Technology | Why |
|---|---|---|
| **Frontend** | React 18 | Component-based, excellent for idle games |
| **State Mgmt** | Context API + useReducer | Simple, sufficient, scales to this complexity |
| **Build** | Vite | Blazing fast dev experience, instant HMR |
| **Styling** | Tailwind CSS | Rapid UI development, responsive by default |
| **Storage** | localStorage | Persistence for save/load, no backend needed |
| **Idle Loop** | setInterval (500ms) | Standard, lightweight, browser-native |
| **iOS** | Capacitor (Week 2) | Web → native iOS wrapper with zero code changes |

### Performance Targets
- Page load: <2 seconds
- Idle loop tick: <5ms execution
- Smooth UI: 60 FPS on 2021+ iPhones
- Bundle size: <500KB gzipped
