# 🎮 GAME DESIGN DOCUMENT (GDD)

## 🧠 Working Title
**The Last Operator** (placeholder)

---

# 1. 🎯 CORE PITCH
A UI-driven strategy simulation game where the player rises to global dominance as a **Businessman, Cult Leader, or Politician** by executing actions through **advisors**, while a global **Doomsday Clock** ticks toward collapse.

> Every shortcut makes you stronger… and brings the end closer.

---

# 2. 🧩 CORE PILLARS

## Advisor-Driven Gameplay
- All actions are executed through advisors
- Advisors shape strategy and outcomes

## Time is the Core Resource
- Every action costs time
- Efficiency vs risk is constant tension

## Meaningful Tradeoffs
- Every gain has a cost
- No optimal path

## Systemic Storytelling
- Events emerge from systems + choices

## Global Pressure (Doomsday Clock)
- Forces urgency
- Player actions influence world collapse

---

# 3. 🧬 PLAYER IDENTITY SYSTEM (INTERVIEW)

## Structure
- 5 questions
- 3 answers each

## Tracks
- Capital (Business)
- Devotion (Cult)
- Legitimacy (Political)

## Traits
- Ruthlessness
- Charisma
- Discipline
- Vision
- Instability

## Outcome
- Highest track = archetype
- Traits modify gameplay + advisor synergy

---

# 4. 🧑‍💼 ADVISOR SYSTEM

## Structure
- Player selects 3 advisors at start
- Advisors provide:
  - Actions
  - Passives
  - Risks
  - Personality

## Example Advisors
- Operator (Money)
- Strategist (Politics)
- Evangelist (Followers)
- Fixer (Problems)
- Media Head (Perception)
- Technocrat (Efficiency)

---

# 5. 🔁 CORE GAME LOOP

1. Choose advisor
2. Select action
3. Pay time + resources
4. Resolve outcomes
5. Trigger events
6. Advance time
7. Doomsday clock progresses
